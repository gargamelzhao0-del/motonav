# 0.2.7：RGB332 显示驱动与全圆地图复测

日期：2026-11-13；设备 COM21，ESP32-S3-Touch-AMOLED-1.75C，CO5300 466 × 466，32 MB Flash、8 MB OPI PSRAM。CPU 240 MHz，QSPI **40 MHz**，双 64 行内部 DMA 缓冲，LVGL/SPI 中断位于 CPU1，NimBLE 位于 CPU0。

## 结果和范围

用户已针对 RGB332 原型的完整地图、文字、圆屏边缘与配色确认：**“画面完整清楚，颜色可以接受”。** 原型应用哈希、观察过程及旧的 16 色错位记录保留在 [低色深复核记录](HARDWARE_TEST_COLOR_MODES_2026-11-13.md)。随后只将 RGB332 转换与已验证的 COLMOD `0x22` 设置整理进入正式驱动；16 色与其调色板、两字节尾包分支均未纳入。

正式源码的开发构建连续测试三种负载，每项 123 秒、包含 2.5 秒预热。FPS 由最后一块像素实际 DMA 完成计数，表中为统计窗口最低值与向下取整平均值；不是定时器次数，也不测量面板物理扫描频率。

| 负载 | 最低 / 平均 FPS | 样本数 | 有效测量 | 转换耗时 / 渲染帧 |
| --- | ---: | ---: | ---: | ---: |
| 局部仪表 | 60 / 61 | 108 | 120.550 s | 0.015 ms |
| 强制整矩形重绘 | 39 / 39 | 109 | 120.565 s | 0.807 ms |
| 466 × 466 全圆模拟地图 | **58 / 60** | 109 | 120.544 s | **0.710 ms** |

地图沿用 7 个路线点、22 条背景道路线段、原来的相机运动及文字覆盖，完整覆盖圆屏；只省去面板外框后不可见的四角。BLE 广播空闲，没有发送手机导航数据。实际手机路线地图尚未接入，因此不能把此结果解释为道路导航、任意地图复杂度或无线并发负载的保证。

地图诊断为 7,554 个渲染帧、60,432 个条带、约 191,967 字节/渲染帧；渲染阶段平均 14.282 ms、DMA 9.833 ms、等待 1.893 ms、文字 0.939 ms。地图准备平均/最大 0.407/0.459 ms。这些时间存在重叠，不能相加作为帧时间。

强制整矩形的渲染阶段为 23.137 ms，DMA 11.103 ms；形状绘制仍限制该负载，未达到最低 40 FPS。地图最低 58，旧原型在测量结束后持续动画还曾出现最低 54，因此**没有稳定锁定 60 FPS 的承诺**。本轮地图约 60 FPS 的平均成绩不适用于全部页面。

## 驱动与应用边界

- `DisplayConfig.color` 默认 `Rgb332`，可选 `Rgb565`；只在初始化时选择，不提供运行中切换格式。
- 应用和 LVGL 继续绘制 RGB565_SWAPPED。驱动在已拥有的当前绘制缓冲内原地转换，然后发送真实字节数；此前 DMA 的完成等待和描述符回收保持原有机制。
- `pixel_pack.cpp` / `pixel_pack_s3.S` 是驱动私有实现：16 字节对齐整数块使用 S3 PIE，四字节对齐和短尾有标量回退；无每帧分配。热代码在 IRAM，掩码在内部 RAM。
- 应用无需接触面板寄存器、汇编、颜色打包或 SPI。`main/` 只增加配置选择与条件测试装配。正常版不链接设备像素校验、模拟地图、性能统计或测试手势。
- `-ColorMode RGB565` 保留完整 16 位配色；`-LegacyQspi` 未指定颜色时自动选择 RGB565。非法组合在构建或初始化时返回错误。

## 检查与设备状态

1. 七个主机程序及依赖边界检查通过。新增检查覆盖全部 65,536 种 RGB565 输入、4–1,024 像素短尾、偏移、重复块、整条带、无效参数与保护区；真实 QSPI 替身检查验证 `0x22/0x55` 命令、非法格式及错误状态。
2. 十二项原生 LVGL 检查通过。39 张 RGB332 预览与独立整数参考逐像素相同，原有缓存/非缓存参考及地图绘制参考仍相同；计时结束保留地图、继续动画和长按退出也通过。
3. COM21 执行实际 SIMD 内核的 **1,094 个检查案例全部通过**，再进入三负载测试。主机只执行标量回退，不能替代这项设备检查。
4. 导出完全不含 `tests/` 的源码并完成默认 RGB332 生产构建，`verify_production.py` 确认未编译测试源、模拟路线或测试组件；另完成 RGB565 厂商 IO 构建和默认构建恢复。
5. 三负载测试未记录 panic、重启或 SPI 提交错误；自动退出后内部可用堆稳定为 61,991 字节。
6. 已将无测试目录产出的正常应用刷入 COM21，仅写 `0x10000`，校验成功。启动日志显示 `Firmware 0.2.7`、`device_tests=0`、`transport=RGB332`；35 秒采集中内部可用堆稳定为 **62,891 字节**。
7. PC 的 BLE 只读复核读到版本 0.2.7、NUS RX write/TX notify 属性；未请求配对或写入导航。正常 UI 回到连接手机流程，模拟地图仅存在于开发测试构建。

未擦除 NVS、改写分区/引导程序或修改 Android。正常版没有固件 OTA，也没有把模拟地图作为真实导航显示。
