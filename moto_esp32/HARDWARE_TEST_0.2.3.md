# 0.2.3 全屏地图与显示回归

2026-11-12，在用户确认的 COM21 / Waveshare ESP32-S3-Touch-AMOLED-1.75C 上测试。ESP32-S3 rev 0.2、32 MB Flash、8 MB OPI PSRAM；ESP-IDF 5.5.4、BSP 3.0.0、LVGL 9.5.0。保持 QSPI 40 MHz、CPU 240 MHz，未超频。

## 显示结果与实现

- 地图由 320 × 300 扩展到完整 466 × 466 圆屏，文字卡片叠加在地图上。用户反馈“已铺满，文字清楚”。保留 `DISPLAY TEST / NOT NAVIGATION` 和 `ROUTE MAP / SIMULATED` 标识。
- 使用有界场景和直接 DMA 条带栅格化，保持原始分辨率。显示格式为 `RGB565_SWAPPED`，两块内部 RAM 缓冲各为 64 行 / 59,648 字节。地图不再分配整幅 PSRAM Canvas；特殊绘制条件使用按需分配的 16 行解码缓冲。
- 地图动态刷新覆盖圆屏的所有像素及 3 像素径向余量，只跳过外框后方的四角。纯主机测试遍历所有可见像素，验证覆盖范围及偶数地址边界；圆屏可见范围的预览与最初全矩形绘制逐像素一致。
- 自定义绘制单元遵守 LVGL 绘制任务顺序；遮挡检查使旧仪表背景不再在地图下重复绘制。该实现使用固定 LVGL 9.5.0 的内部接口，升级 LVGL 必须重新验证解码、覆盖及任务调度。
- LVGL 软件绘制同步运行于适配器任务。显示任务与 SPI 中断同在 CPU1，BLE 在 CPU0。亮度命令在显示任务启动前完成；真实 DMA 回调保留适配器 FPS 计数，并用信号量及显式 ISR 调度唤醒显示任务。
- 正常固件的手动测试保留短按切换、长按退出。自动测试显示 `AUTO TEST` 并记录、忽略触摸，以避免截断计时；配对或有效导航仍可接管并释放地图资源。

## 最终实测

测试镜像由 `tools/build.ps1 -DisplayBench -BenchSeconds 123` 生成。每项约 123 秒，扣除 2.5 秒预热；三项自动完成后返回正常连接页。BLE 处于广播状态，没有手机导航流量。

| 负载 | 采样最低 FPS | 采样平均 FPS | 样本数 | 预热后测量时间 |
| --- | ---: | ---: | ---: | ---: |
| 局部 HUD | 58 | 59 | 108 | 120,509 ms |
| 强制整矩形全屏重绘 | 32 | 32 | 108 | 120,503 ms |
| 466 × 466 圆屏动态地图 | 35 | 36 | 108 | 120,525 ms |

地图样本仍为 7 个路线点、22 条背景道路线段及方向标记，相机持续平移和旋转。测量区间内准备场景 4448 次，平均 424 μs、最大 464 μs；这只统计投影及失效区域准备，栅格化和显示传输发生在之后，不能当作完整帧时长。

地图期间日志采样的总空闲堆范围为 7,965,368–7,966,068 字节，内部空闲堆为 55,287–55,987 字节。最终测试未见 panic、watchdog 或 DMA 等待超时，三项均按计划退出。

**全屏地图尚未达到至少 40 FPS 的目标**。FPS 来自完整刷新最后一块 DMA 完成计数，每约 1.1 秒采样；最低值是采样窗口最低值，平均值是整数样本均值，不代表逐帧延迟上界。不能把 0.2.2 的 320 × 300 地图 41/42 FPS 当作此版全屏成绩，也不能外推至 512 点上限、任意道路密度、中文文字叠加或 BLE 导航并发。

证据：`dist/COM21-0.2.3-full/serial-regression-final.log`、`flash-regression-locked.log`、`motonav-regression-locked.bin`。

## 调试与稳定性范围

初始整幅地图 Canvas 仅约 18–19 FPS；按需条带、遮挡处理、面板字节序及直接绘制逐步改善性能。早期快速传输测试曾卡在 SPI 提交阶段，主程序仍在运行。随后调整亮度初始化顺序、DMA 等待与 ISR 调度，并把 SPI 初始化及显示任务放在同一核心。最终上述连续测试未复现早期停滞；这仍不代替长时间骑行与手机并发验收。

部分早期测量被手动触摸中断，用户已确认操作。另一次重启后的早停没有完整退出记录，因此也不作为验收数据。原始日志保留在本地，只有三项自动完整结束的 `serial-regression-final.log` 用于本表。

## 软件验证与正常版交付

- 四组纯主机测试通过：NAV3 帧/CRC/会话/时效、状态与条带边界、10,000 条随机裁剪线段、2,000 组栅格形状；新增条带/裁剪区域像素一致性及圆屏覆盖检查。
- 五项原生 LVGL 检查通过：正常启动、自动三负载、自动地图、解码回退，以及直接绘制与回退图像一致性。覆盖动画、误触不截断自动测试、配对和有效导航接管、手动退出及资源清理。
- 正常构建关闭两个自动测试选项及 `CONFIG_MOTONAV_BOOT_DISPLAY_TEST`，COM21 刷写校验及启动记录确认为 `Firmware 0.2.3 / NAV3`，开机进入连接页。电脑 BLE 读取版本 `0.2.3`，确认 RX `write`、TX `notify`，随后断开；没有请求配对或发送导航数据。
- 正常应用镜像 SHA-256：`d36cce66c3048655a6eef0c42e7e3b875a6bc50bcaea00828c1b96c3939b4b8d`。仅刷写应用地址 `0x10000`，分区表与 NVS 保留；正常版证据见 `dist/COM21-0.2.3-production/`。
- 真实导航仍使用 NAV3 箭头仪表；当前全屏地图是明确标记的模拟样本。手机 PIN 配对、真实 NAV3 持续导航、锁屏和断连恢复须继续按 [PHONE_INTEGRATION.md](PHONE_INTEGRATION.md) 联调。
