# MotoNav 独立恢复测试工程

从可恢复的0.6源码建立，**不是0.10原源码或完整功能恢复，不用于实际骑行**。
包名 `com.motonav.recovery`，当前版本 `8 / 0.7.0`。
与旧MotoNav并存，不读取旧App私有数据，不要求卸载旧版；原仓库sim目录保持不变。

## 本次实现
- 真实导航由前台服务持有，手机锁屏、切换应用及地图页面重建后继续运行。导航通知提供结束操作。
- 真实地图页新增圆屏选择和系统配对，使用带 CRC、会话编号和数据时效的 BLE v3 发送真实转向、距离、车速及等待状态。断线后重连已选择的设备并发送当前状态。
- 配套 1.75C 固件和协议说明见 [圆屏接收端](../moto_esp32/README.md)。Android 编码结果直接进入 C++ 接收器测试。
- 地图设置中的「应用更新」支持手动检查和可选的后台新版提醒。发布工作流生成同签名 APK 和校验清单，下载与安装由使用者确认。详见 [应用更新与发布](docs/SECURE-UPDATES.zh-CN.md)。
- 桌面启动直接进入真实地图页；首次设置后自动隐藏配置面板。
- Android Keystore保护AES-GCM加密保存Android Key；禁用备份，不写Key日志、Intent或Bundle。
- 保存版本化隐私同意。支持撤回同意、删除加密配置和设备密钥；停止地图不依赖写盘成功。
- 每次前台检查系统实际定位权限。首次请求粗略/精确定位；拒绝或撤销后不循环弹窗，主动重试才再请求或打开设置。
- 地图前台使用独立的高德高精度连续定位，并补齐 Wi-Fi 辅助定位与 A-GPS 所需的权限。区分卫星、Wi-Fi、基站和系统网络等来源，保持新位置的15秒时效。粗定位供地图预览，只有合格的精确位置可用于算路。无回调时自动重启定位请求。地图预览在离开页面时停止定位，已启动的导航由前台服务独立继续。
- 保留0.6模拟功能入口，模拟数据不代表真实导航。

## 本次继续恢复（需对应CI及真机验证）
已加入真实POI搜索/地点选择、按实际车牌与排量提交摩托路线（车型11/策略2001）、路线预览和显式启动的GPS导航HUD。路线成功前不能启动；错误16明确提示高德服务授权不足。导航回调提供转向图标、下一道路、剩余距离/时间。
本版增加锁屏定位和向已配对圆屏发送实时导航数据，因此同意版本提升到3，老测试配置需要重新阅读确认一次。车辆信息只用于本次内存会话，不写本App持久存储。
新导航组合SDK为11.3.100_3dmap11.3.100_loc11.3.000_sea9.8.1，替换原地图组合包，定位组件版本也随组合变为11.3.000。必须重新做定位实机回归。
单次请求状态机防止迟到回调覆盖、重复规划和取消后误启动。路线60秒或起点变化超过60米需重规划。短时失锁会保留路线并隐藏旧指令，新的合格位置与导航指令都到达后恢复显示。长时间失去定位时持续等待，新的可信位置及指令到达后恢复。偏航或SDK要求更新路线时仍结束本次导航，需要重新规划。
SDK自动偏航/拥堵重算关闭接口未获验证；本App收到重算事件即停止，不声称阻止了SDK内部所有重算请求。无自动重算成功保证。

## 构建
使用JDK17、Gradle8.9和Android SDK35，在android-recovery目录执行：
- `sh tests/run.sh`
- `gradle --no-daemon assembleDebug lintDebug`

本仓库只含文本源码和配置，不含二进制Gradle wrapper、APK、Key或签名私钥。GitHub Actions执行测试、编译和lint，并输出保留7天的临时签名停车测试APK、清单及签名指纹。正式发布使用独立的稳定签名流程。

## 0.3 圆形地图视觉（未实机验收）
使用 TextureMapView 实现圆形小地图、哑光表圈、夜间底图及紧凑的真实导航信息卡。无虚构速度、限速、朝向或路况。页面可滚动以容纳横屏和较大字体，地图手势不应被外层滚动截获。
高德原标识保持默认大小，移动到圆内底部中央；没有重绘或隐藏标识。路线预览自动切换完整图以免端点被圆形裁掉。提供“圆形/完整图”切换以查看角落路线和排查设备裁剪问题。需真机确认 logo 完整可见、TextureView裁剪、地图手势、窄屏/横屏/大字体、按键和导航文本。编译或静态检查不等同这些验证。
稳定签名尚未生成或上传。建议用户持有离线加密备份，在确认保管方案后再授权受控构建使用；公开仓库不得保存私钥或密码。当前 CI 的临时 debug 密钥不保证跨次构建一致，只提供一次性停车测试APK，不是可持续升级安装包。

## 临时测试包安装提示
从对应提交成功运行的 Actions artifact 获取APK、certificate.txt与SHA256SUMS.txt。用 certificate.txt 中的 Signer certificate SHA-1 digest 绑定高德Android平台Key，包名为 com.motonav.recovery；可在App设置核对本安装SHA1。首次输入Key后加密保存在本App，不要发到聊天或仓库。
每次CI可能生成不同签名，下次APK可能无法覆盖此测试版；不得为此卸载原MotoNav或清除原数据。首次实验保存的信息应视为不可迁移；后续固定签名前先确认安装迁移方案。不要使用此包骑行；尚未真机验证鉴权、定位、路线、圆形logo和权限流程。

## 0.4 定位交互和诊断修复（历史）
修复搜索/路线预览后按定位不能返回当前位置的问题：显式定位重试恢复FOLLOW，已有新位置时立即居中，没有新位置时重新启用定位层。读取地图定位回调官方 ERROR_CODE，鉴权/网络失败明确显示错误码，不记录SDK原始详情或Key；失败、无效坐标、模拟位置和过期结果均不进入算路起点。权限拒绝、系统定位关闭或具体SDK错误不再被通用等待文案覆盖。加入数据检查和接线回归测试。仍未真机复现用户报告的症状，不声称已修复所有设备定位问题。

## 0.4时的远程更新评估（0.5进展见后文）
0.4及此前版本没有应用内版本检查、APK下载、更新安装或远程升级入口。已交付0.3使用未持久保存的临时debug签名；新版不能保证覆盖安装，不能通过添加更新按钮解决签名不一致，也不能假设保留原配置。
后续先由用户确认固定签名及私密备份/构建保管方案，再设计HTTPS版本清单（versionCode、下载地址、SHA256、证书标识）、APK哈希与签名校验、明确更新说明、由用户确认安装。不要绕过安卓安装权限、关闭安全检查或静默安装。不能恢复原签名时须明确新包并存与重新配置策略，不卸载旧App、不清除旧数据。此轮没有创建密钥、凭据、更新服务器或发布服务。

定位边界复查：0米精度不再被视为有效，和算路门槛保持一致；系统定位关闭或权限撤销时清空旧点，迟到回调不能恢复旧点。每次取算路/导航位置快照都会重新检查精确权限、系统开关和时效，不依赖5秒提示计时器。纯Java与静态接线检查覆盖这些门槛，仍需真机验证系统切换竞态。

## 0.5 应用内更新基础设施（未发布远程版本）
地图设置新增“应用更新”：用户主动检查固定GitHub仓库的发布清单，选择下载，校验大小/SHA256/包名/更高版本/实际当前签名后，再由用户交给Android安装器确认。未知来源安装权限由用户自行选择开启，返回后不会自动继续。无后台轮询、静默安装、卸载或数据清除。详见 docs/ 中的更新说明。
此功能仅写入新版本源码，不会自动出现在已安装0.3中。尚未创建长期签名、凭据或正式Release/清单，检查可能提示尚未发布。CI临时签名不同的APK会被严格拒绝。不能恢复现有临时私钥时首次转稳定签名需用户决定新包并存，或卸载本测试App后重新安装（会丢失其Key/设置）；不涉及也不应卸载原MotoNav。不会承诺无损迁移。本轮没有执行卸载、配置长期签名或发布远程版本。
