# MotoNav 0.7.25

- 配合圆屏固件 0.3.16，补充真实底图中的住宅、商业、工业用地，学校、医院、停车及施工场地，以及河流、溪流等水系线。新增类别来自原始 OSM 瓦片，按局部视野筛选。
- 用地、场地、水系与建筑、道路分层绘制，补充原来只有单色背景的街区；保留导航路线与定位点的显示优先级。
- 新增 NAV4S6 能力协商。连接旧固件会自动回退，继续显示旧版支持的类别；新图层需圆屏 0.3.16。GATT 服务不变，无需因本次协议升级重新配对。
- 底图统计明确区分“整块瓦片源数据”与“当前局部图元”，避免把视野外建筑误认为传输丢失。保留统计复制、截屏和诊断导出。

使用原正式签名覆盖升级，无需卸载或重填地图 Key。地图仍来自 OSM
Shortbread，不能补出源数据没有收录的商户、建筑或名称。场景上限仍为
384 个图元、24 个标注，地铁线没有当作驾车道路绘制。本次主要补充地图
类别，不代表复杂地图已经达到 40 FPS。
