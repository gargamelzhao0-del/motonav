# MotoNav Android 0.7.7

固定签名，versionCode 15。继续使用普通驾车导航。

- 修复真实 Android Emulator 中复现的时钟兼容问题：GPS 将日历时间的纳秒数填入开机计时字段时，新位置会被误判为未来时间。现在仅在两个字段能确认同属一次日历时间测量时转换，仍检查原始测量时间，过期、任意未来值和来源限制不放宽。真机是否同因需诊断确认。
- 新增“地图设置 → SDK 模拟导航测试”。使用本机已保存的 Key 和北京公开测试路线，由真实高德 SDK 算路并进行模拟导航，不依赖当前位置。显示实际位置与导航指令回调次数，最长 90 秒，离开页面停止。
- 模拟导航与真实导航互斥，不会向圆屏发送模拟指令。必须收到实际回调才显示通过，不能用模拟成功证明 GPS 正常。
- 将原来合并的“定位或导航指令中断”拆成 GPS 信号弱、地图定位过期、SDK 位置仍更新但地图定位过期、尚无指令、指令过期等原因。
- 诊断日志分别记录地图定位、导航 SDK 位置和导航指令的时效与计数，不记录坐标、道路名或 Key。收到无效导航帧时及时关闭播报。
- 增加真实 Android Emulator 测试：实际 APK、Activity 生命周期、Android/高德数据对象、SDK 初始化回调和定位/指令中断回放。

此版提供可重复的定位手段，不宣称已确认异地手机的 GPS 根因。CI 不持有用户有效 Key，不把初始化回调或合成轨迹测试当作线上导航成功。真机 GPS、道路匹配及圆屏 40 FPS 仍需实测。
