# MotoNav Android 0.7.2

增加可主动开启的定位诊断和异地实时日志，继续使用 0.7.1 的固定签名。已安装固定签名 0.7.1 的手机可在「地图设置 → 应用更新」中下载并覆盖安装，无需重新配置高德签名。

## 如何诊断

1. 在「地图设置 → 定位诊断 / 实时日志」粘贴调试方提供的本次诊断连接。
2. 点「开始实时诊断」，返回地图复现定位过期或无法算路。
3. 出现问题后可返回诊断页点「标记：刚刚出现问题」。页面显示上传是否被接收端确认。
4. 完成后点「停止诊断与上传」。会话最长 60 分钟，进程重启后默认关闭。

没有诊断连接时可选「仅在手机记录」，然后导出最近诊断文件。断网会限量缓存并重试；队列满时显示丢弃计数。本地最多保留约 1 MiB，Java 崩溃的最后记录可能只保存在手机，需要重新打开后导出。

## 记录内容

定位来源、精度、测量时间年龄、回调间隔、有效点被拒绝的原因、卫星状态、权限、网络类型、省电状态、App 生命周期、算路提交和 SDK 错误码。还会记录临时会话编号、App/Android 版本及手机品牌型号。

不会记录经纬度、目的地、车牌、高德 Key、道路名称、设备唯一标识或 SDK 原始错误文本。HTTPS 上传经 Cloudflare 临时通道到调试电脑；会话凭证只保留在内存，不写入日志或仓库。

本次还修复了填写车辆信息期间定位过期后，点击提交算路却没有反馈的问题：现在明确提示请求尚未发出并保留目的地。定位数据有效期和精度门槛没有放宽，定位问题的最终原因需根据实机日志确认。

编译、Lint、Java/C++ 回归及 Java 编码到 HTTP 接收端的认证、隐私字段、重放、限额和过期验证由构建执行。服务端接收到记录不等于定位问题已修复，也不等于手机安装已实测。
