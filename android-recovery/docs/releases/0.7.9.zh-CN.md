# MotoNav Android 0.7.9

这一版整理导航主页与操作流程，延续 0.7.8 的连续定位和 NAV4 圆屏路线能力。

- 完整地图作为默认视图，圆屏视图仍可切换；增加日间地图选择，显示偏好保存在本机。
- 开始、取消与结束导航放在固定底栏；导航启动后把指引卡放到顶部，突出转向距离、道路、车速、剩余距离和用时。
- 设置与诊断从主页收起；统一深色配色、字号、按钮尺寸与系统安全区域，适配横屏及大字体。
- 搜索词、加载、错误和结果保留在同一个窗口；支持键盘搜索，失败可直接重试，取消或超时后的旧结果不会改变目的地。
- 结束导航和清除地图配置增加确认；无效 Key 保留在输入框供修改，敏感输入仍禁止保存到页面状态和自动填充。
- 圆屏扫描增加说明、未发现设备提示与重新扫描入口。
- 更新页面保留下载进度与续传，按阶段显示下载、暂停和安装操作；诊断页显示当前记录状态。

使用固定签名，可覆盖升级 0.7.1 及以后的固定签名版本；安装仍由 Android 系统确认。

定位质量门槛、来源时间、隐私同意和 NAV3/NAV4 协议保持原有规则。界面中的等待状态不会保留过期转向、车速或距离。

导航仍是普通汽车驾车路线，不含摩托车禁限行避让。界面验证使用 Android 模拟器和公开测试样本；不代表异地手机的定位问题已全部解决，也不代表圆屏真实导航并发的帧率已验收。
