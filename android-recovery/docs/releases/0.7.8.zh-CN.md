# MotoNav Android 0.7.8

固定签名，versionCode 16。普通驾车导航。

- 导航期间使用经过 GPS 模式、原始时间、精度和权限检查的导航 SDK 位置。独立地图定位停更时，只要导航 GPS 和指令仍有效，就继续引导；重复、过期、未来时间、网络定位和低精度 SDK 结果不会续命。地图页面显示当前导航定位的精度和年龄。
- 新增 NAV4 完整路线地图通道，适配 ESP32 0.3.0：手机发送真实路线片段、当前位置、转向、距离及速度，圆屏本地绘制。旧固件继续箭头导航，App 会说明需要更新固件才能显示路线地图。
- 路线与导航信息在同一有界快照中校验和提交，支持 MTU 23；断开、结束、等待和来源过期会隐藏地图及旧引导。保留 NAV3 兼容。
- 扩展圆屏数据说明，需要再次确认一次地图/导航同意，已保存的 Key 保留。路线和位置经已配对的加密蓝牙发送给圆屏，诊断日志不加入坐标。

显示为完整圆屏真实路线图，不含周边建筑/道路底图、中文路名或天气。0.7.7 的 SDK 模拟测试仍与真实 BLE 导航隔离。

30 分钟确定性位置流回放、控制器恢复、Java/C++ 跨端协议和 Android Emulator 检查用于发现软件问题；异地手机是否同一根因、手机/圆屏联合运行及 40 FPS 仍需实机验证。
