# MotoNav Android 0.7.5

本版按用户选择改为普通驾车导航，沿用固定签名，versionCode 为 13。

## 导航改进

- 使用普通汽车车型和驾车算路策略，主页面持续显示“普通驾车”。无需填写车牌和排量。
- 自动获取当前位置，输入并选择目的地后，点击“开始导航”自动算路并启动。
- 准备启动时若起点移动超过 60 米，会自动重新规划；最多追加两次请求，共用原有 60 秒启动期限。
- 前台导航服务交接过程中短暂失去位置，会保留路线并等待新定位恢复后启动；取消或超时后不会被迟到回调重新启动。
- 偏航及拥堵重算时保留导航服务，隐藏旧路线、转向和圆屏指令。成功后更新为 SDK 当前路线，收到新位置和新指令后继续显示。重算失败、无效或 30 秒超时会明确结束导航，目的地保留。
- 区分网络连接、Key/签名鉴权、服务权限和额度错误，便于定位问题。
- 继续提供更新下载进度、固定签名覆盖升级、持续定位恢复和主动开启的远程诊断。

普通驾车路线不包含摩托车禁限行避让，也不按车牌做个性化限行判断。高德 Key 仍需具备相应驾车导航服务权限并匹配包名、签名及配额；切换路线类型并不保证消除所有错误 16。当前版本尚未增加语音播报。

## 安装与验证

已安装固定签名 0.7.1 或更新版本，可从“地图设置 → 应用更新”检查、下载并验证，再交给系统确认安装；也可下载此 Release 的 APK 覆盖安装。无需卸载或清除已有配置。

本版增加执行真实 JourneyController 的 SDK/UI 替身测试，覆盖普通驾车参数、定位等待、起点变化、前台交接、偏航/拥堵重算、取消、无效结果及超时。发布流程执行完整回归、Android 编译与 Lint、APK 签名和更新清单一致性校验。替身及构建验证不能代替手机实测，真实定位、导航鉴权、偏航和圆屏显示仍需在设备上确认。

实现依据：[高德导航事件回调](https://a.amap.com/lbs/static/unzip/Android_Navi_Doc/com/amap/api/navi/AMapNaviListener.html)、[AMapNavi 路线接口](https://a.amap.com/lbs/static/unzip/Android_Navi_Doc/com/amap/api/navi/AMapNavi.html)、[算路错误码](https://a.amap.com/lbs/static/unzip/Android_Navi_Doc/com/amap/api/navi/enums/PathPlanningErrCode.html)。
