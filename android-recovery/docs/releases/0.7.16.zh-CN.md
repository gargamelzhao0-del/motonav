# MotoNav 0.7.16

配合 ESP32 固件 0.3.7，圆屏改为当前位置附近的局部导航地图，镜头随导航移动，不再默认缩放显示整条路线。

- 接入 OpenStreetMap 真实道路、建筑、水域和绿地；高德继续提供路线与导航指令。
- 手机后台下载和缓存当前视野数据，通过蓝牙分块发送；圆屏本地绘制，导航状态优先于底图传输。
- GPS 较弱时保留路线起点附近或最后可信位置附近的地图，显示等待定位；不显示虚构车速或车辆位置。
- 圆屏显示转向卡片、速度、规划/剩余距离及时间、指南针和地图来源。
- 使用原稳定签名，可覆盖升级。旧固件继续使用原有路线/箭头显示。

更新后打开真实地图页，需要同意新增的 OpenStreetMap 底图数据用途一次。原地图 Key 保留。连接 MotoNav 圆屏，选择目的地并开始导航；首次加载底图需要联网，暂不可用时会重试。

底图会按设备容量简化；数据覆盖依赖 OpenStreetMap，当前不含中文路名字体、实时路况、限速和天气。完整驾车定位仍需可信 GPS。该导航使用普通驾车路线，不提供摩托车禁限行避让。
