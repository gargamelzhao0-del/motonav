# MotoNav Android 0.7.12

- 修复实时诊断持续显示“正在连接、待发送 0 条”的问题：日志队列正则中的结束花括号未转义，Android 的 ICU 引擎拒绝初始化。现在显式转义，兼容 Android 与桌面 Java。
- 后台日志队列初始化异常会显示具体异常类型，不再静默停留在连接中；远程队列失败时仍尝试保存本地诊断文件。
- 区分“正在准备日志队列”“正在连接接收端”和“远程接收已确认”，只有收到匹配的服务端回执且确认落盘后才显示上传成功。
- 新增 Android 模拟器回归：实际日志写入、重启恢复、回执落盘，以及完整上传流程对错误回执的保留和正确回执的确认。网络边界使用受控替身，不向真实接收端发送测试数据。

使用固定发布签名，可覆盖升级 0.7.1 及以后的固定签名版本。圆屏无需重新刷写。本次修复日志采集通路；周期性定位失效和真实 NAV4 路线显示仍需手机日志与实机联调确认。
