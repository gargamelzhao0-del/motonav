# MotoNav Android 0.7.6

固定签名，versionCode 14。继续使用普通驾车导航，不包含摩托车禁限行避让。

## 定位与导航恢复

- 修复启动前定位短暂丢失、恢复后位置已明显变化却仍启动旧起点路线的问题。GPS 启动前再次检查当前起点和路线时效，变化超过 60 米时重新规划。
- 从点击“开始导航”起，由前台服务负责定位、算路和启动；切到后台、锁屏、地图页面重建不再取消尚未完成的启动。启动仍有 60 秒总期限，起点变化最多追加两次算路，取消后迟到结果不能重新启动。
- 导航中暂时断网、服务暂时异常或重算超时，会保留导航会话，等待可信定位并按 5、10、20、40、60 秒退避重试。新的请求使用请求编号过滤旧结果。Key、服务权限、额度及无效路线等不能通过网络重试解决的错误仍明确停止并保留目的地。
- 修复圆屏停止回执尚未完成时，立即再次开始导航被旧服务状态拒绝的问题。
- 开启高德内置语音播报，地图设置提供开关。缺少新位置、新指令或正在重新算路时暂停播报，恢复可信引导后再开启。实际语音资源与音量仍需手机验证。

## 更新下载

- 下载交给独立前台服务，切换页面或锁屏继续下载，通知和更新页面显示进度。
- 支持暂停、恢复和 HTTP Range 断点续传；网络失败或进程退出后，重新进入更新页面可继续。服务器不支持 Range 时安全重下；过期缓存会被清理。
- 完成后重新校验整个 APK 的大小、SHA256、包名、版本及签名，安装前再次验证。下载不会自动安装；正在导航时要求先结束导航再进入安装器。
- 本功能从安装 0.7.6 后生效；升级到本版的下载仍使用手机当前旧版的更新逻辑。

## 异地诊断

- 远程诊断增加持久待传队列，收到服务器确认并保存确认状态后才移除记录；正常停止、断网及进程退出后保留尚未确认的记录。
- Java 崩溃事件同步落盘，重新打开 App 并主动连接诊断后补传。仅本地记录的会话不会自动进入远程队列，连接凭证仍不持久保存。
- 默认 1 小时，可选择本次记录 4 小时；接收连接必须仍有效。队列上限 4096 条 / 2 MiB，溢出会丢弃最早记录并显示计数。此机制不保证捕获 native 崩溃、系统强杀前尚未生成的事件或存储故障。

## 验证与边界

增加起点移动约 1110 米、后台完成启动、网络重试和旧结果隔离、语音启停、持久日志重放与 ACK、残缺写入恢复，以及 Range 响应边界测试。保留既有定位、更新安全、诊断接收与 Java/C++ 圆屏协议回归。发布流程执行 Android 编译、Lint、固定签名及升级连续性校验。

真实手机的定位根因、高德服务授权、后台策略、实际音频，以及手机与圆屏配对和 40 FPS 仍需要设备实测。本版不把室内粗定位或缓存伪装成导航级位置，也不声明已完成硬件帧率验收。
