# MotoNav Android 0.7.11

- 修复开启实时诊断时可能无响应的问题：日志队列恢复、保存、读取待传批次和确认落盘统一由文件线程处理；开始、停止和状态刷新不等待磁盘。
- 停止诊断时异步关闭网络连接，避免等待正在进行的 TLS 操作；状态使用内存计数，队列拥塞会显示丢弃数量。
- 优化旧日志去重恢复，避免逐条遍历已有记录。保留持久待传队列、接收确认后移除、断网补传及有效期限制。
- 优先上传当前诊断会话，历史未确认记录继续补传，避免旧日志积压延迟当前问题的观察。
- 发现不到 NAV4 时延迟进行一次公开 API 服务重新发现，再决定是否使用兼容的 NAV3；不调用隐藏蓝牙 API，不反复重连。
- 增加导航 SDK 原始测量年龄和 GPS 弱信号诊断字段，便于排查周期性定位失效；定位有效期与精度判定保持原有规则。

通过 25 项实际 Diagnostics 类阻塞测试，覆盖恢复、确认落盘、连接关闭和满队列；同一测试在修复前代码上可复现界面调用被阻塞。另通过 39 项实际 BleLink 类回调测试。它们使用可控边界替身，仍需手机复测确认。

使用固定发布签名，可覆盖升级 0.7.1 及以后的固定签名版本。当前圆屏固件为 0.3.2；本次无需重复刷写圆屏。定位周期性失效的具体原因仍待手机日志确认。
