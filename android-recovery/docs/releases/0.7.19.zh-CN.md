# MotoNav 0.7.19

- 配合圆屏固件 0.3.10，定位点与转向指引独立显示。GPS 弱或暂时没有导航指令时，仍可显示手机最近测得的位置。
- 大致位置显示黄色定位点和精度提示；精确位置尚无指引时显示蓝色点，可信导航恢复后显示白色方向车标。
- 位置使用原始测量时间计算有效期。过期、断线、停止或到达后清除，不使用路线起点冒充当前位置，也不把低精度位置用于导航指令和车速。
- 自动兼容旧圆屏固件，保持原有地图、转向信息及蓝牙实时诊断。沿用正式签名覆盖升级，保留 Key 和设置。

旧固件无法显示新增的独立定位点，请与 0.3.10 一起更新。定位点可见并不表示室内 GPS 已达到导航精度。
