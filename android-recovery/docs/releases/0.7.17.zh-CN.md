# MotoNav 0.7.17

配合 ESP32 0.3.8，改善真实地图的完整性、首次显示速度和配色。

- 按完整道路和建筑筛选底图，避免单独裁掉线段或建筑的一半；按当前视野分配细节，地图容量翻倍。
- 先显示附近已下载的底图，再补齐外围细节。补充数据时保留已显示的地图。
- 行进或转向后更新当前视野的地图细节；继续优先发送实时导航和结束指令。
- 圆屏默认恢复全彩 RGB565，并明确显示“底图就绪 / 无 GPS”，区分加载与等待定位。
- 原签名覆盖升级，保留地图 Key 和配对信息。已在 0.7.16 同意底图说明的用户无需再次确认。

GPS 弱时地图停留在路线起点或最后可信位置附近，不会产生模拟车辆运动。首次底图仍需联网；OpenStreetMap 缺少的数据无法由软件补出。旧圆屏固件继续使用兼容模式。
