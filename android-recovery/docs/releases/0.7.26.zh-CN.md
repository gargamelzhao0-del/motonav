# MotoNav 0.7.26

- 配合圆屏 0.3.17，通过 App 已有的高德官方搜索 SDK 补充周边小区、学校、商圈、医疗和交通站点等名称。道路、建筑、水系继续使用 OSM 矢量底图；补充名称按真实坐标投影，筛选当前局部视野，保持路线和定位点优先。
- 周边搜索独立运行，不阻塞底图、导航或蓝牙任务。每批最多 3 个分类请求、每类 25 个结果，相邻批次至少间隔 60 秒；静止时 5 分钟刷新，移动超过 300 米后按限频刷新。只在本次导航内存中保留，结束导航清除。
- 圆屏改进名称避让：常规视图最多显示 8 个名称，区域名和地标名均可多处显示；图标放不下时，具体地标文字仍可单独显示。临近转弯时减少标注，避免遮挡指引。
- “圆屏底图完整性”增加高德查询状态、收到数量、局部采用数量、成功/失败请求数及错误码，仍可一键复制。新旧圆屏自动协商，旧版继续显示 OSM 地图，无需重新配对。

请覆盖安装，无需卸载或重新输入地图 Key。首次打开真实地图页需重新同意扩展后的名称查询用途，然后连接圆屏并开始导航。

名称是否收录取决于地图服务，当前视野和屏幕容量仍会限制同时显示数量；本次不保证每个商户、每个小区都可见，也不代表复杂地图已经达到 40 FPS。若补充失败，原有地图与导航仍可使用，复制底图统计可看到具体错误码。
