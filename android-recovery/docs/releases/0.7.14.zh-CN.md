# MotoNav Android 0.7.14

- 新增“开始蓝牙实时诊断”：手机通过已配对圆屏，将导航关键状态转发到电脑 USB 串口，不需要公网链接或手机 USB 调试。需要圆屏固件 0.3.4。
- 每秒发送一条固定字段摘要，包括定位/指令年龄、等待原因、导航序号与回执，以及手机源状态和实际编码的圆屏状态，帮助排查“手机有指引、圆屏等待”的原因。
- 导航优先发送，诊断缓存有界；停止、到期或断线后不补发旧诊断。摘要不含坐标、目的地、Key 或任意日志文本。完整日志仍保存在手机，可单独导出。
- 老圆屏固件继续使用原导航协议，诊断页会提示缺少诊断服务。原有公网诊断和本地导出入口保留。

固定签名覆盖升级。升级后在真实地图页设置中进入诊断，点“开始蓝牙实时诊断”，保持圆屏蓝牙连接和 USB 连接电脑即可。本次增加排查能力，不代表已经修复具体手机上的等待问题；真实链路及导航并发效果需实机验收。
