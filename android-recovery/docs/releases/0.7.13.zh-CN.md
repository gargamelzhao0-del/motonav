# MotoNav Android 0.7.13

- 修复静止时高可信网络定位因缺少原始来源字段而被全部丢弃的问题：高德 `SAME_REQ` 表示短间隔或位置几乎未变化时的前次定位，高可信等级表示周边信息仍新鲜。现在单独标记为“可信网络复核”，不冒充 GPS，也不要求可选来源字段必须存在。
- 仍核对实际测量时间、严格递增顺序、15 秒有效期、精确位置权限和 100 米精度；低可信回调、明确缓存、离线位置及过期测量继续拒绝。明确来自基站或模糊定位的回调保留原有限制。
- 连续有效的静止复核不再因被误拒绝而触发定位客户端重启。真实断流的自动恢复机制继续生效。
- 圆屏处于箭头导航时，提示改为“暂未发现路线地图服务”，避免直接误报固件版本不足；诊断记录区分地图服务及其收发特征是否存在。
- 增加定位原始来源诊断和 Android 实际 SDK 对象回归。室内 GPS 信号弱仍会等待实时导航引导，不用网络复核替代卫星导航测量。

使用固定签名覆盖升级；圆屏本次无需重新刷写。真实手机效果仍需继续复测。

参考：[高德定位类型](https://lbs.amap.com/api/android-location-sdk/guide/utilities/location-type)、[AMapLocation 可信等级](https://a.amap.com/lbs/static/unzip/Android_Location_Doc/com/amap/api/location/AMapLocation.html)。
