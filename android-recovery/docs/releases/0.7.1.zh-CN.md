# MotoNav Android 0.7.1

这是使用固定发布签名的首个安装基线。后续正式 APK 继续使用同一个签名，手机可在「真实地图 → 设置 → 应用更新」中检查、下载并确认安装，也可开启新版提醒。

## 安装与迁移

- 下载本 Release 的 `MotoNav-0.7.1.apk`。GitHub Actions 的临时测试 APK 使用其他签名，不属于此更新渠道。
- 包名为 `com.motonav.recovery`，versionCode 为 9。
- 已安装的 0.6.1、0.7.0 等临时签名包无法直接覆盖为这个固定签名版本。手机需要先完成一次安装迁移；仅发布清单不能改变旧包签名。
- 请先保留自己掌握的高德 Key 和必要配置。卸载测试应用会删除它的本地数据；本发布不自动卸载、清除数据或保证无损迁移。
- 高德 Android Key 需绑定此包名和以下固定证书 SHA1：`70:FC:4D:12:38:EC:21:EF:AB:81:14:D6:9A:4F:3A:63:F4:A1:91:45`。
- 后续同签名版本由 App 校验包名、版本、SHA256 和实际签名，再交给 Android 安装器确认。

## 包含的功能

继承 0.7.0 的真实摩托导航、前台导航服务、弱定位等待与恢复，以及向配对 1.75C 圆屏发送实时转向、距离和速度信息。定位权限和高德配置仍需在手机上完成。

此版本开通固定签名的远程更新渠道。锁屏导航、BLE 配对与显示性能尚未完成实机验收；动态地图和至少 40 FPS 不在本次交付中，固件 OTA 尚未提供。

发布构建执行 Java/C++ 协议测试、Android release 编译与 Lint、APK 签名验证、固定签名指纹核对及发布版本连续性检查。手机上的安装成功与配置恢复仍需实测。
