# MotoNav 0.7.18

配合 ESP32 0.3.9，把圆屏的导航布局、透视和字体按仓库模拟器重新实现。

- 发送当前道路、下一道路和预计到达时刻，圆屏支持常用简体中文路名。
- 转向卡片、车速数字、紫色路线亮点、地图上下渐变和罗盘采用模拟器的视觉参数。
- 保留真实周边道路与建筑、局部视角跟随和分批底图更新，不再以整条路线总览作为默认导航画面。
- GPS 弱时保留地图，隐藏车辆标记和失效的实时道路信息；限速没有可信来源时显示“--”。
- 自动协商新版显示信息，兼容旧圆屏固件；沿用正式签名覆盖升级，保留 Key 和设置。

模拟器的规则城市是演示数据。实际道路、建筑形状取决于当地 OpenStreetMap 数据，缺失建筑不会用虚构建筑补齐；室内没有可信定位时地图不会模拟行驶。离屏预览和显示测试不代表真实道路导航已验收。
