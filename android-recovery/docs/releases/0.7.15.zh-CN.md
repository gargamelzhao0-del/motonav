# MotoNav Android 0.7.15

- 修复“手机已规划路线，圆屏却只有 WAITING FOR GUIDANCE”：配合圆屏固件 0.3.6，已规划路线独立于实时定位发送，GPS 弱或暂时没有导航指令时显示全屏路线总览。
- 总览使用真实规划路线，不显示车辆位置、车速或过期转向。获取可信位置和新指令后自动切换为实时导航；结束导航、到达或断开连接时清除路线。
- 新旧协议自动协商，旧固件仍可使用原有导航；保留蓝牙实时诊断。升级没有更换蓝牙服务表。

固定签名覆盖升级。需要同时使用圆屏固件 0.3.6 才能在首次实时指引到来前显示路线。此版本显示路线几何，尚未提供周边街道、建筑或地图瓦片底图；也不会把室内粗定位当作可信车辆位置。
