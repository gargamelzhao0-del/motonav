# NAV4：完整圆屏路线快照

协议实现基线：Android 0.7.8、ESP32 0.3.0。当前集成为 Android 0.7.10、ESP32 0.3.2（0.2.7 RGB332 驱动）；Android 0.7.9 继续兼容，协议字节格式不变。NAV3 保持兼容，旧 App/固件继续显示箭头。NAV4 是真实导航输入，不用于 SDK 模拟测试。独立服务保证旧接收器不接收新增消息。

服务 `91c40001-6b5d-4f1a-b817-52e0baf8a430`；有响应 RX `91c40002-6b5d-4f1a-b817-52e0baf8a430`；通知 TX `91c40003-6b5d-4f1a-b817-52e0baf8a430`。广播仍带 NUS 服务以兼容扫描。发现 NAV4 特征后订阅其 TX，经过原有 PIN 认证加密后握手。0.3.2 起，已订阅通道的第一次认证 RX 写入选择本连接的协议；持久 CCCD 按句柄恢复的顺序不决定协议。选择后不能由 NAV3 和 NAV4 同时修改导航，退出当前通道订阅后清空输入状态。

所有整数为小端，字段连续无填充。有符号数使用二补码。固定头 13 字节：`M4` 两字节、uint16 总长度、uint8 类型、uint32 序号、uint32 会话。序号/会话范围 1..2147483647，每次连接从 HELLO 序号 1 开始。尾部 uint32 为 CRC-32/ISO-HDLC，覆盖它前面的全部字节，包括头和长度。

HELLO 类型 1，总长度 17，无负载，确认 `A,sequence,NAV4\n`。快照类型 2，确认 `A,sequence,OK\n`。非法数据 `E,NAV4\n`。确认是 ASCII，最大序号也能在 MTU 23 中通知。

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 13 | uint8 | mode：1 等待、2 有效、3 到达、4 结束 |
| 14 | uint8 | 高德转向 icon |
| 15 / 19 / 23 | int32 | 转向距离 m、剩余 m、剩余 s |
| 27 | int16 | km/h，未知 -1 |
| 29 / 31 | uint16 | 定位及指令年龄 ms；包含发送方的 3000 ms 传输预算 |
| 33 | uint32 | 局部坐标系/路线窗口版本；无地图时 0 |
| 37 | uint8 | 路线点数：0 或 2..64 |
| 38 / 40 | int16 | 当前位置局部 x/y，单位 m |
| 42 | int16 | 正北顺时针航向，0..3599 表示 0..359.9°；未知 -1 |
| 44 | 点数组 | 每点 int16 x、int16 y，范围 -32000..32000 |
| 44 + 4 × 点数 | uint32 | 整帧 CRC |

快照总长 `48 + 4 × 点数`，最大 304 字节。Android 按 20 字节串行有响应写入，至多 16 次写入；只有完整 CRC、所有字段和导航时效都通过，才一次性替换地图与指令。每秒发送一次最新完整快照，停止/等待优先于地图输出，不存在独立路线队列阻塞导航的情况。传输失败超过 3 秒断开并重新握手。

有效导航的范围与 NAV3 一致；非有效 mode 的距离/时间/速度为 -1、图标和年龄为 0，同时地图字段为 version/count/x/y=0、heading=-1。没有可发送路线窗口时，允许有效导航带零个地图点，圆屏显示箭头降级视图。相同序号及校验和只重发 ACK，不延长数据寿命；不同内容重复序号、旧序号或其他会话均拒绝。地图在流中断 4 秒或来源年龄达到原 15 秒有效期后隐藏。

地图采用手机 SDK 的 GCJ-02 路线和位置投影到同一局部坐标系，x 朝东、y 朝北，单位米。原点只在手机持有；设备收到的每帧自包含相对坐标，不需要经纬度，也不能据此推断全球坐标。窗口移动超过 250 米或路线更新会生成新的版本。近点选择只用于裁剪显示几何，不生成转向。保留连续路线前后约 500/1000 米和顺序，简化误差上限 8 米；超出 64 点、4096 原始窗口点或坐标范围时省略地图，保留有效箭头。

背景不包含模拟道路、建筑或未获得的地图瓦片。设备只绘制真实路线、当前位置和导航信息；未知航向采用北向上，未知速度显示 `--`。相机在两个已接收位置间做最多 900 ms 视觉过渡，不推算未来位置，不修改年龄或导航数字。真实动态地图和蓝牙并发下的 40 FPS 需上板另测。

复现：`android-recovery/tests/run.sh` 会执行 Java 编码、C++ 生产接收器与会话的跨端检查。`tests/lvgl_host` 使用正式 UI 渲染导航地图和失效状态；这些是主机/模拟器证据，不代表手机 PIN 配对和道路测试已经通过。
